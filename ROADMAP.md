# Roadmap

Wir bauen eine kleine <b>Order-API</b> mit Spring Boot und wenden dabei diesen Ablauf an:

1. Requirements klären
2. Projekt initialisieren
3. Testfälle definieren
4. Alle Tests zuerst fehlschalgen lassen
5. Minimalen Code implementieren
6. Tests grün bekommen
7. Refactoring
8. SOLID und Design Pattern erklären
9. Spring-Integration ergänzen
